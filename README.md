# WordGameFinal

**WordGameFinal** — это словесная головоломка в жанре Wordle, разработанная на движке Unity. Игрок должен угадать загаданное слово за 6 попыток, используя визуальные подсказки и анализируя статистику своих игр.

---

##  Игровой процесс

* **Механика угадывания:** 6 попыток на ввод слова. Буквы меняют цвет в зависимости от точности попадания (правильная позиция / есть в слове / отсутствует).
* **Панель статистики:**
  * Учет общей статистики: количество сыгранных игр, процент побед, текущая и максимальная серии побед.
  * Наглядная гистограмма распределения побед по попыткам (1–6).
* **Кастомный UI:** Стилизованный тёмный интерфейс с акцентными оливковыми и бежевыми тонами.

---

##  Технологический стек

* **Engine:** Unity
* **Language:** C#
* **UI Framework:** Unity UI (uGUI) + TextMeshPro
* **Architecture:** Component-based UI Management (Vertical Layout Group, Content Size Fitter, Layout Elements)
* **VCS:** Git

## Запуск и сборка
Клонируй репозиторий:


git clone [https://github.com/your-username/WordGameFinal.git](https://github.com/your-username/WordGameFinal.git)

Убедись, что используется правильная версия Unity.

Открой сцену Assets/Scenes/MainScene.unity и нажми Play.
